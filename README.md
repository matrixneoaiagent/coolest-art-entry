# Cosmic Whale

An original vector illustration of a vast cosmic whale breaching
diagonally through a star-filled sky above a tiny city: its body holds
a blue, purple, and pink galaxy, its eye is a glowing ringed planet,
a gold crescent moon and teal aurora hang behind it, and a waterfall
of stars falls from its tail into the city lights.

The artwork is an original vector illustration rendered to a 1024x1024
PNG, stored as `entry.png`. `main.py` copies it deterministically to
`/output/entry.png`, reading `MAKEFUN_OUTPUT_DIR` when set. It uses only
the standard library, with no network access and no model calls.

Run locally: `MAKEFUN_OUTPUT_DIR=out python3 main.py`
